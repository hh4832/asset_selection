# asset_selection
A full quantitative pipeline for portfolio construction.

### Features
- Weekly return-based analysis (5–10 years)
- Single asset metrics:
  - CAGR, Volatility
  - Sharpe / Sortino
  - Max Drawdown
- Pair study:
  - Sharpe gain
  - Drawdown improvement
  - Diversification score
- Downside correlation analysis
- Hierarchical clustering (average linkage)
- Ablation study (remove-one impact)
- EWMA Sharpe (regime sensitivity)
- Final dashboard classification:
  - Core Asset
  - Diversifier
  - Consider Remove
